# 主题图像来源

应用的图像预设包含第三方作品的数字复制图和修改后的合成图。这些来源图像不因项目源码采用 Apache License 2.0 而改变权利状态。

| 资源 | 来源及处理 |
| --- | --- |
| `theme_starry.jpg` | 梵高《星月夜》的[维基共享资源文件](https://commons.wikimedia.org/wiki/File:Vincent_van_Gogh_Starry_Night.jpg)；文件页标记 Public Domain Mark。 |
| `theme_fan_kuan.svg` | 以范宽《谿山行旅图》的[维基共享资源文件](https://commons.wikimedia.org/wiki/File:Fan_Kuan_-_Travelers_Among_Mountains_and_Streams_-_Google_Art_Project.jpg)为中心参考，左右为生成并修订的延展区域；这是合成设计图，不是原作原样复制。来源文件页标记 Public Domain Mark。 |
| `theme_earthrise.svg` | 使用 [NASA《地出》图像](https://science.nasa.gov/resource/image-earthrise/)制作合成图，移动了画面中的地球位置；不是未经修改的纪实照片。来源：NASA / William Anders。使用时遵循 [NASA 图像指引](https://www.nasa.gov/nasa-brand-center/images-and-media/)；NASA 未认可或赞助本项目。 |

不同法域对作品复制图和修改图的处理可能不同。需要再次分发这些图像时，请核对各来源页面和适用条件。
